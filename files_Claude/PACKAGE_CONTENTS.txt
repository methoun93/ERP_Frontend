📚 PAGE CREATION PATTERN
═══════════════════════════════════════════════════════════════════════════════

Step 1: Create config (2 mins)
────────────────────────────
export const MyPageConfig: CrudMasterConfig = {
  title: 'My Item',
  endpoint: apiRoutes.myEndpoint,
  idKey: 'myItemId',
  gridCols: 3,
  fields: [...]
};

Step 2: Create page (1 min)
──────────────────────────
@Component({
  selector: 'app-my-page',
  template: '<app-crud-master [config]="config"></app-crud-master>'
})
export class MyPage {
  config = MyPageConfig;
}

Step 3: Add route (30 secs)
──────────────────────────
{ path: 'erp/my-module/my-page', component: MyPage }

TOTAL TIME: 3.5 minutes per page!

🔌 API INTEGRATION
═══════════════════════════════════════════════════════════════════════════════

CrudMaster automatically handles these API calls:

✅ GET /endpoint?page=1&limit=10&search=xyz    → List with pagination
✅ GET /endpoint/{id}                           → Get single record
✅ POST /endpoint                               → Create record
✅ PUT /endpoint/{id}                           → Update record
✅ DELETE /endpoint/{id}                        → Delete record

Your backend API just needs to follow this pattern. No special setup needed!
